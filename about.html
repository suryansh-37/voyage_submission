About This Application

This web application demonstrates direct data communication between a PostgreSQL relational database (ClassicModels dataset) and an interactive web interface.

The backend is built with Python and Flask using the psycopg2 library to query the database. The frontend uses standard HTML, CSS, and vanilla JavaScript to render the records in real time.

The dashboard fetches and displays complete customer records including company details, contact information, full addresses, sales representatives, and credit limits.
