About This Project

I made this project to learn how to connect a PostgreSQL database to a Python Flask backend and display data on a webpage.

The dataset used is the Classic Models database, which has tables like customers, orders, payments, employees, and offices.

In the dashboard page, you can see all the customer details from the customers table. You can also click "View Orders" to see recent orders and total payments made by each customer.
